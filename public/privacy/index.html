Leftly privacy policy

Privacy Policy

Last updated: September 19, 2026

Leftly is a local-first paycheck budgeting app. This policy describes the data handling that is implemented in the current web application.

Local-only use

You can use Leftly without creating an account. In that mode, budget data is stored in your browser's local storage on the device and browser you use. This can include pay-period details and income, bills, expenses, categories and category targets, recurring Bill Plan items, preferences, display settings, History snapshots, setup drafts, the active tab, and backup/recovery activity timestamps. Clearing browser storage or resetting app data can remove local data.

Leftly lets you choose to export a JSON backup or CSV records. Exported files are created by your browser and are handled where you save or share them. A JSON backup may contain your budget data and can be imported into Leftly. CSV exports are for records and are not restore files.

Optional account and cloud backup

If the optional cloud-backup feature is enabled and you choose to use it, Leftly uses Supabase for email magic-link sign-in, session handling, and cloud backup. Supabase processes the email address used for sign-in, its account identifier, authentication/session information, and the backup snapshot you choose to upload.

Cloud backup is manual, not live sync. Leftly stores one latest snapshot per signed-in account; uploading replaces that account's prior snapshot. A cloud restore replaces Leftly data on the current device but does not delete the cloud copy. Local reset and demo-data actions do not delete a cloud snapshot. To request help with a cloud account or snapshot, use the support route below; do not post sensitive data publicly.

Network services and third parties

The current app uses Supabase only when optional cloud backup is configured and used. The app has no implemented bank connection, advertising SDK, analytics SDK, telemetry SDK, or crash-reporting SDK. The app does not require an account for core budgeting.

Choices and security

You control whether to use optional cloud backup and when to export or import files. Keep backup files private because they may contain financial information. No method of storage or transmission is guaranteed to be secure; this policy does not make regulatory or security-certification claims.

Changes

We may update this policy as the app changes. The date above indicates the latest revision.
