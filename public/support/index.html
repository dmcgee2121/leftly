Leftly support

How can we help?

For everyday guidance, open the in-app Help / About / Feedback section. Leftly works locally in your browser; keep a JSON backup when you want a portable recovery copy.

Recovery basics

  • Use JSON backup to save a restoreable copy of your Leftly data.
  • Use the app's JSON import flow to restore a saved backup to this device.
  • CSV exports are useful for spreadsheet records, but cannot restore data into Leftly.
  • Optional cloud backup is manual and retains one latest snapshot for a signed-in account; it is not live sync.

Current support channel

Report product issues through Leftly GitHub Issues. GitHub Issues are public. Do not post private financial data, passwords, JSON backup files, email addresses, or other sensitive information in an issue.

A dedicated public support email is an owner decision required before store submission. No support email is published here yet.
